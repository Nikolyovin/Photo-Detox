# 🧹 Фото-Детокс (Photo-Detox)

**Фото-Детокс** — это бесплатное приложение для Android, которое помогает быстро и безопасно очистить галерею вашего смартфона от визуального мусора.

Мы не показываем рекламу, не просим подписку и **не отправляем ваши фотографии на сервер**. Всё работает локально на вашем устройстве.

## ✨ Главные фишки (v1.0.0)

- **Свайп-интерфейс:** Удаляйте ненужные фото движением пальца влево, а нужные — вправо. Интуитивно понятно, как в Tinder, только для галереи.
- **Безопасная корзина:** Случайно удалили важное фото? Не беда! Оно отправится в корзину, где будет храниться **7 дней**. Вы можете восстановить его в любой момент или удалить навсегда.
- **Умная сортировка:** Отдельная вкладка для скриншотов, чтобы быстро очистить залежи мемов и переписок.
- **Кнопка «Отменить»:** Если вы случайно свайпнули не то фото, просто нажмите «Отменить» на всплывающей плашке.
- **Приватность (100% Local):** Приложению нужен доступ к галерее только для того, чтобы показывать вам фото и удалять их. Никаких аналитических трекеров и отправки данных.

## 🛠️ Технологический стек

Проект написан на современном стеке, с упором на плавность анимаций и типизацию:

- **React Native** + **Expo (SDK 58)**
- **TypeScript** (строгая типизация всех компонентов и данных)
- **React Native Reanimated** (плавные 60 FPS свайпы)
- **React Native Gesture Handler** (обработка жестов)
- **Expo MediaLibrary** (доступ к галерее)
- **AsyncStorage** (хранение корзины и настроек онбординга)

## 🚀 Как запустить локально

Если вы разработчик и хотите посмотреть на код или собрать проект самостоятельно:

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Nikolyovin/photo-detox.git

   ```

2. Установите зависимости:

   ```bash
   npm install

   ```

3. Запустите Metro Bundler:

   ```bash
   npx expo start

   ```

4. Отсканируйте QR-код через приложение Expo Go на вашем Android-устройстве.
